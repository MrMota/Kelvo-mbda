Built on Ollama, from the first line

AI agents that run on your own models

Kelvo is a visual builder for agents, tools and skills. Every model call goes to your own Ollama. It installs three Python packages, starts in under a second and keeps working when the internet doesn't.

Three steps to a working agent

No account, no API keys to buy. Just your Ollama and a browser.

1

Point it at Ollama

Kelvo finds your models at 127.0.0.1:11434, or any Ollama you choose. Pick a default model once and every template uses it.

2

Build on the canvas

Start from Simple Agent or a blank canvas. Drag in an Agent, give it tools and skills, and connect the ports. Ports only fit where the data fits.

3

Talk to it, then ship it

Chat in the Playground and watch each tool call as it happens. Then call the flow from your apps over REST, or from any MCP client.

Skills

Agents that pick up a skill when they need it

Write a skill once: a name, when to use it, and the instructions. Agents see only the name and the "when". The full text loads the moment a request calls for it, so small local models stay fast and on task.

  • A skills library you can search and edit
  • Import and export the SKILL.md format
  • Give an agent every skill, a chosen few, or write one inline

Small, local, and honest about errors

The things that make self-hosting painful, fixed first.

Ollama-native

Every component speaks Ollama

Chat models, embeddings and structured JSON output. Replies stream into the chat even when they pass through an agent. Pull new models from Settings.

Light

Three dependencies, one file

FastAPI, Uvicorn and HTTPX, with everything stored in one SQLite file. Startup makes no network calls, so air-gapped servers boot as fast as your laptop.

Clear

Errors that say what to do

"Can't reach Ollama. Start it with ollama serve." Failed components light up on the canvas with the reason, and every run is logged.

Agents

Tools, memory, teams

Switch any component into a tool. Agents remember the session, and a lead agent can hand work to another agent.

Knowledge

Split documents, embed them with an Ollama model and search them, with no vector database to run.

Connect

REST API and MCP

Copy-paste code for cURL, Python and JavaScript, with sessions, runtime overrides and streaming. Expose any flow as an MCP tool.

Questions

Do I need a GPU?

No. Ollama runs on CPU too, just slower. Start with a small model such as qwen3:4b or llama3.2:3b. A GPU or Apple silicon makes agents with many tool calls feel much quicker.

Which models work for agents?

Agents need a model that can call tools, such as qwen3, llama3.1 or mistral-nemo. If a model can't call tools, Kelvo tells you and suggests one that can.

Does anything leave my machine?

Model calls go only to the Ollama address you set. Kelvo has no telemetry. The only outbound requests are the ones your flows make, for example when an agent uses the URL tool to read a web page.

Can I bring flows from other visual builders?

Not yet. There's no importer for other tools today. Kelvo flows import and export as JSON, so you can move them between Kelvo installs and keep them in git.

Can my apps and other agents use what I build?

Yes. Every flow has a REST endpoint with API keys, sessions and streaming, and you can expose any flow as a tool on Kelvo's built-in MCP server.

Is it ready for teams?

Not yet. Kelvo is single-user today. Keep it on your machine or a private network. Team features (SSO, roles, shared flows) are what the Team plan is for, and they're in development.
